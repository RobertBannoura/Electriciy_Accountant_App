## Defects fixed during QA

1. Production PWA deep links used a relative Vite base and relative registration URLs, causing direct-route reload failures. The application now uses root-relative assets, manifest, and service-worker URLs.
2. Browser/Electron print-to-PDF produced visually correct Arabic whose glyph mapping was not reliably searchable. PDF export now uses React PDF with embedded Amiri Regular/Bold fonts and saves the generated bytes through a validated Electron IPC handler or a browser download.
3. The PDF generator initially lost or clipped the repeated statement header at an automatic page boundary. Statements now paginate deterministically and repeat their complete header and table heading on every A4 page.
4. The 80mm invoice header widths did not match its compact row widths. Receipt-specific columns now total 100% and align correctly.
5. Correction movements could fall back to a mixed technical label. They now render as `تصحيح رصيد`.
6. HarfBuzz shaping WebAssembly was blocked by the client CSP. The policy now permits only same-origin scripts plus the narrowly required `wasm-unsafe-eval` capability.
7. PDF saving now validates sender origin, payload size, PDF signature, and safe filename; the VAPID private key remains server-only.

## Environment limitations

- No production VAPID key pair or real browser push subscription was supplied. End-to-end provider delivery was therefore not sent to an external push service; configured/unconfigured UI behavior, payload construction, admin filtering, deduplication, failure isolation, and stale-subscription cleanup were covered locally.
